# learning

个人学习资料目录，通过 GitHub Pages 在线浏览。

## 访问

仓库为 Public 且 Pages 已启用，推送 main 后自动部署，地址为：

https://<你的用户名>.github.io/learning/

## 目录

- [ai.html](ai.html)

## 维护

- [COVERAGE.md](COVERAGE.md)：题库与大纲的覆盖/反推记录。维护用，考生不用读。

追加新资料：把 html 放到仓库根目录，并在 `index.html` 的
`MATERIALS` 数组加一项 `{ title, file }`，侧栏即自动出现。
